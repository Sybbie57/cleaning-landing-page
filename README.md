# 🧼 Cleaning Service Landing Page

A clean and professional HTML landing page designed for a cleaning service business. This project focuses on simple structure, user-friendly layout, and clear service presentation.

## 🚀 Live Demo

https://github.com/Sybbie57/cleaning-landing-page.git

## 📌 Features

* Hero section with call-to-action
* Services section
* About section
* Contact form
* Simple and clean design
* Beginner-friendly HTML structure

## 🛠 Built With

* HTML5

## 🎯 Purpose

This project was created to practice building real-world business landing pages that can be used for freelance work.
